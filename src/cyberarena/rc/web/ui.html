Flagwake Offline

Responder Check · open source · runs offline

Test how your security defender handles an incident.

Your defenderThe program you want to test. It reads alerts and decides what to do. works through simulated incidents in an invented company. Its decisions are scored in business cost, and anyone can re‑check the result.

The demo runs two built-in example defenders on the same incidents. It takes about two seconds and needs no model.

1

Connect a defender

A program, a model endpoint, or a product with its own tools.

flagwake defenders add
2

Run incidents

Practice incidents to try things; fresh ones, drawn for each run, for results you share.

flagwake run --defender NAME
3

Verify the result

Every number is re-derived from the stored commands. An edited report fails.

flagwake verify report.json
